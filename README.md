# Her Majesty

A tiny 11:11 page for Anishka, live at **[prettiestwomanalive.in](https://prettiestwomanalive.in)**.

She opens the link, sees a glowing **11:11**, taps it to make a wish, and then
your message appears line by line.

## Change the message

Edit **`js/message.js`** — that's the only file you need. Commit and push, and the link updates.

## Running it

No build step. Plain HTML, CSS and JS served from the repo root
(`python3 -m http.server` works for a local preview).
